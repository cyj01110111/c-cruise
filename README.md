# c-cruise · 智能小车定点巡航系统模拟

大一上嵌入式培训 · **C 语言验收项目**（对应《大一上培训任务V2》第一阶段验收项目）。

在有限指令次数内（最多 5 次）通过选择挡位（1/2/3）让模拟小车从 0 行驶到 100 的目标距离：
用结构体管理小车状态，用函数拆分核心逻辑与历史记录显示。

## 编译运行

```bash
gcc -Wall -Wextra -std=c11 src/main.c -o cruise
./cruise          # Windows 下为 cruise.exe
```

## 运行规则（任务书要点）

| 挡位 | 模式 | 实际前进距离 |
|---|---|---|
| 1 | 安全模式 | 15 |
| 2 | 普通模式 | 25 |
| 3 | 狂暴模式 | 40 − k（k = 本次是第几次指令，第 1 次使用即 40−1 = 39） |

- 每次输入后累加距离，并把本次挡位记入 `history` 数组
- **第 2 次指令执行完**：若当前距离 < 40 → 输出「警告：进度落后，建议提升挡位！」
- **第 4 次指令选择时（读取输入之前）** → 输出「电机过热预警：连续高负荷运行，注意挡位选择！」
- 5 次内达到 ≥ 100 → 「巡航成功！顺利抵达终点，共耗费指令 X 次。」并立即结束
- 5 次用完仍未达标 → 「巡航失败！电量耗尽，距离终点还差 XX 个单位。」
- 无论成功与否，最后必须调用 `showHistory` → 「小车历史挡位记录为：X X X……」
- 非法输入（非 1/2/3）：提示重新输入，且**不计入指令次数**（任务书未规定，为本次实现的合理约定）

## 结构体与函数

```c
typedef struct {
    int targetDistance;    /* 目标总距离，固定 100 */
    int currentDistance;   /* 当前已行驶总距离 */
    int commandCount;      /* 已发送指令次数 */
    int maxCommands;       /* 最大指令次数，5 */
    int history[5];        /* 每次选择的挡位 */
} CruiseSystem;

void runCar(CruiseSystem *sys);      /* 核心运行逻辑 */
void showHistory(CruiseSystem sys);  /* 显示历史挡位 */
```
